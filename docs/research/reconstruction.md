# Reconstruction spec research: Catmull-Rom (Phase 0, feeds Phase 2)

The flagship feature: PRISM mandates its scaling math so a file renders identically at any size in every viewer. This note pins down the chosen kernel and the two real spec problems (minification and determinism). Visual comparisons get generated by the Phase 2 renderer itself.

## The kernel

Catmull-Rom is the Keys cubic with a = -1/2. As a convolution kernel over normalized distance x:

    k(x) = 1.5|x|^3 - 2.5|x|^2 + 1            for |x| <= 1
    k(x) = -0.5|x|^3 + 2.5|x|^2 - 4|x| + 2    for 1 < |x| < 2
    k(x) = 0                                   otherwise

Equivalently, the interpolated value between samples p1 and p2 with neighbors p0 and p3, at fraction t:

    f(t) = 0.5 * ( 2*p1 + (p2 - p0)*t + (2*p0 - 5*p1 + 4*p2 - p3)*t^2 + (3*p1 - 3*p2 + p0 - p3)*t^3 )

## Why this kernel

It interpolates: k(0) = 1 and k(n) = 0 at every other integer, so the surface passes exactly through the stored samples. That is the property our lossless story requires; at native resolution the reconstruction IS the original pixels, bit-exact, with no special casing. B-splines are smoother but approximating (they blur samples unless you prefilter, which breaks the mental model); Lanczos-3 is sharper but rings at hard edges, needs 6 taps against Catmull-Rom's 4, and its sinc evaluation invites cross-implementation drift. Catmull-Rom is also separable: scale rows then columns with the same 1D kernel, identical result to the 2D evaluation.

## Spec details to fix in Phase 2

1. Edges: clamp (repeat the border sample) for the virtual neighbors outside the image. Simple, standard, deterministic.
2. Alpha: interpolate straight alpha channels independently in v1 and document the known fringe caveat, or premultiply internally before filtering and un-premultiply after. Decide with test images; premultiplied filtering is the technically correct choice and likely wins.
3. Color space: filtering in gamma-encoded sRGB is what nearly every viewer does and is cheap; filtering in linear light is physically right. v1 mandates gamma-space filtering for cost and compatibility, recorded explicitly so v2 can add a linear flag.
4. Minification: Catmull-Rom used raw aliases when scaling down. The spec must define downscale as the same kernel stretched by the inverse scale factor (support widens, weights renormalized). This is the standard high-quality resize construction and keeps one kernel for both directions.
5. Determinism, the hard one: "identical in every viewer" requires defining the arithmetic, since IEEE 754 float behavior varies with evaluation order and FMA use. Options: (a) mandate f32 with a fixed evaluation order and no FMA, (b) mandate fixed-point integer arithmetic with defined precision and rounding, (c) define a small tolerance and a conformance test corpus. Leaning (b) for bit-exact conformance; integer-only also keeps the door open for no-FPU targets. The Phase 2 implementation decides with benchmarks.

## Non-goals

No ML upscaling, no invented detail, ever; it would break the format's honesty guarantee. Alternative kernels arrive, if ever, as declared header options with their own conformance vectors.
